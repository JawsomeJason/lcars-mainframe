# today

Starts the day: fresh numbers into today's note, then the single most important next move.

## Read first

1. This file. 2. `FINDINGS.md`. 3. `SKILL.md`.

## Pull in only

- Today's daily note (create it from `00 Human/80 Templates/Daily.md` if missing).
- Yesterday's daily note: unfinished tasks and its `## Activity` log.
- Open tasks in `00 Human/20 Tasks/` with a `due_date` on or before today, or `status: blocked`.
- Active projects in `00 Human/30 Projects/` (properties and `## Next steps` only).

## Never

- Type a number into a property. The collector script does that.
- Rewrite the owner's Focus or Tasks wording. Suggest; they decide.

## Output

A short plan in chat. If the owner accepts it, the chosen #1 goes into today's `## Focus`, in their words.
