# close-day

Ends the day: what got done is ticked, what did not is carried forward, and the log is complete.

## Read first

1. This file. 2. `FINDINGS.md`. 3. `SKILL.md`.

## Pull in only

- Today's daily note.
- Tasks in `00 Human/20 Tasks/` the owner mentions or that today's note links.

## Never

- Mark a task done unless the owner said it is done.
- Write a reflection or summary of the day into the note. If the owner wants one, they write it; you can ask them questions.

## Output

Updated task properties, and tomorrow's note with carried-over tasks (if the owner wants it created now).
