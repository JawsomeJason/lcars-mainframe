# Machine: your side

This is where agents and scripts work. Write and edit freely: drafts, research, logs, intermediate files, finished outputs. The owner does not need this side to be tidy, but they need to be able to find what you made.

| Folder | What goes here |
|---|---|
| `Workflows/` | Repeatable jobs, one folder each. Read `Workflows/AGENTS.md` before running or adding one. |
| `Scripts/` | Code that runs without a model: collectors that fill daily numbers, helpers. |
| `Outputs/` | Deliverables and drafts. One folder per job: `YYYY-MM-DD <short name>/`. |

## Rules

- Link anything you make from today's daily note `## Activity` line, so the owner can find it.
- Do not move your output into `00 Human/`. The owner promotes what they want to keep as their own.
- No secrets in files. Scripts read keys from environment variables.
