# Machine/Outputs

Finished deliverables and drafts produced by workflows and agents.

## Rules

- One folder per job: `YYYY-MM-DD <short name>/`. Put a `README.md` in it saying which workflow made it and from what inputs.
- Link the folder from today's daily note `## Activity` line.
- HQ shows the newest Markdown files directly in this folder as recent work. Put a one-page summary here when the owner should see the result in HQ.
- Do not delete old outputs without asking; they are the history workflows learn from.

> **Owner overrides:** if an `AGENTS.local.md` sits beside this file, read it next. Where the two disagree, `AGENTS.local.md` wins.
