# 90 Content

The content tracker. One note per piece of content (an idea, a video, a post, an email), created from `../80 Templates/Content Idea.md` and saved in `Ideas/`. HQ's Content page reads `Ideas/`. `Content.base` shows every content note as one table.

What gets tracked (platform, format, status values, performance numbers) is the owner's choice, set during onboarding in the `Content Idea.md` template.

## Rules

- `status` uses only the values listed in the template.
- Ideas are written in the owner's words. Your research, angles, and drafts go in `Machine/Outputs/` and get linked from the note's `sources` or body.
- Performance numbers (views, likes, and so on) come from scripts or the platform, never from an estimate. Unknown stays `unknown`.
- What worked and what flopped is a lesson for the content workflows: record it in that workflow's `FINDINGS.md`, not here.

> **Owner overrides:** if an `AGENTS.local.md` sits beside this file, read it next. Where the two disagree, `AGENTS.local.md` wins.
